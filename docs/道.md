# 道

万物循因果运行，不以人的意志为转移。

## 最高层

存续：强化则存，搁置则衰，唯结构可抗。
行为：行为由结构决定，与意志无关。
认知：凡经人手必失真，唯对证可正。
失序：凡未闭环必乱，唯收敛可稳。
命运：命运由文化属性决定——强势文化按律行事，弱势文化寄望救主，皆不以人的意志为转移。

## 最底层

识律：认识规律，不凭经验与教条。
筑构：把规律固化为结构，替意志与记忆执行。
常检：以检验校正失真，替自觉纠错兜底。

## 一以贯之

意志能改变的不是规律，而是对规律的认识与顺应。
见路不走：不因别人走过的路、自己走过的路、看起来对的路而走，只按规律指明的路走。

以上，即一切。
